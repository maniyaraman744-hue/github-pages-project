Host a Static Website with GitHub Pages

## Project Overview

This project demonstrates how to host and deploy a static website using **GitHub Pages**. The website is created using HTML and CSS and published directly from a GitHub repository.

GitHub Pages provides free hosting for static websites without requiring a separate hosting server.

## Objective

To create a simple static website and deploy it using GitHub Pages so that it can be accessed publicly through a live URL.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Website styling and design
- GitHub – Source code management
- GitHub Pages – Website hosting and deployment

## Workflow

1. Created a project folder on the local machine.
2. Created an `index.html` file to build the website structure.
3. Created a `style.css` file to add styling.
4. Created a new public repository on GitHub.
5. Uploaded the HTML and CSS files to the repository.
6. Opened repository Settings.
7. Navigated to Settings → Pages.
8. Selected **Deploy from a branch**.
9. Selected the `main` branch and `/ (root)` folder.
10. Saved the configuration.
11. GitHub Pages automatically built and deployed the website.
12. Opened the generated live URL and tested the website.

## GitHub Pages Configuration

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- HTTPS: Enabled

## Advantages of GitHub Pages

- Free static website hosting.
- Easy deployment from GitHub repositories.
- Supports custom domains.
- HTTPS support.
- Automatically updates the website after publishing new changes.

## Limitations

- Supports static websites only.
- Does not execute backend code such as PHP, Python or Node.js.
- Does not provide a database.
- Has publishing and usage limits.

## Interview Questions and Answers

**1. What is GitHub Pages?**

GitHub Pages is a free hosting service that allows us to deploy static websites directly from a GitHub repository.

**2. Can GitHub Pages host dynamic applications?**

No, GitHub Pages mainly supports static websites using HTML, CSS and JavaScript. It does not run server-side backend applications.

**3. How do you update a website?**

We update the website files in the GitHub repository and commit the changes. GitHub Pages automatically deploys the updated content.

**4. What is the default homepage file?**

The default homepage file is `index.html`.

**5. Can we use a custom domain?**

Yes, GitHub Pages supports custom domains by configuring DNS records.

**6. What happens if we delete the repository?**

The website hosted from that repository will no longer be available.

**7. What is deployment?**

Deployment means making an application or website available to users.
